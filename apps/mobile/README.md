# The Table Mobile Prototype (Expo)

This app is a UI scaffold aligned with `mobile/ui-screens.md`.

## Run
```bash
npm install
cp .env.example .env
npm run start
```

## Environment placeholders
- `EXPO_PUBLIC_API_BASE_URL`
- `EXPO_PUBLIC_MAPBOX_ACCESS_TOKEN`
- `EXPO_PUBLIC_ONESIGNAL_APP_ID`
- `EXPO_PUBLIC_S3_BUCKET_NAME`

Leave placeholders for prototype mode until service accounts are ready.
